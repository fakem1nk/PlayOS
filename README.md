## Идея

Игры на компьютере разбросаны по лаунчерам, эмуляторам и папкам. Чтобы просто поиграть с дивана, приходится тянуться к мыши.

PlayOS собирает их в одно место и превращает компьютер в приставку: включили, выбрали обложку, играете. Всё управление — с геймпада, всё хранится у вас на диске.

<br>

## Что внутри

**Одна библиотека.** Игры из Steam находятся сами, образы PS2 узнаются по серийному номеру диска, игры PS3 подтягиваются из RPCS3. Обложки, фоны и логотипы — из Steam, SteamGridDB и Википедии.

**Поверх любой игры.** Кнопка PS открывает меню прямо в игре: игра встаёт на паузу, рядом сохранения эмулятора, громкость, звук, яркость и заряд геймпада.

**Время и трофеи.** PlayOS считает часы по сессиям и показывает настоящие трофеи — RetroAchievements для PS2 и достижения Steam для PC.

**Живой интерфейс.** Цвет обложки разливается по меню, фон оживает трейлером, а когда вы отходите от экрана, включается тихое слайд-шоу ваших игр.

**DualSense по-настоящему.** Через DSX световая панель принимает цвет игры, мигает при трофее и краснеет, когда садится батарея.

**Обновляется сам.** Новая версия скачивается в фоне и ставится при выходе.

<br>

## Управление

| | PlayStation | Xbox | Клавиатура |
| --- | :---: | :---: | :---: |
| Играть, выбрать | ✕ | A | Enter |
| Назад | ○ | B | Esc |
| Параметры игры | △ | Y | M |
| Добавить игру | ▢ | X | F |
| Вкладки | L1 / R1 | LB / RB | Q / E |
| Меню в игре | PS | Guide | Ctrl + Alt + H |

<br>

## Установка

Скачайте `PlayOS-Setup.exe` со страницы [релизов](https://github.com/fakem1nk/PlayOS/releases/latest) и установите в любую папку. При первом запуске короткий мастер поможет добавить игры и настроить экран.

Библиотека и настройки хранятся в `%APPDATA%\PlayOS` и переживают переустановку.

<br>

## Сборка из исходников

```bash
npm install
npm run dev
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запуск с горячей перезагрузкой |
| `npm run web` | Только интерфейс в браузере, на демо-данных |
| `npm run dist:setup` | Установщик в `release/` |
| `npm run release` | Установщик и черновик релиза на GitHub (нужен `GH_TOKEN`) |
| `npm run typecheck` | Проверка типов |

## Принципы

**Локально.** Никаких аккаунтов PlayOS и облака. Библиотека — один файл на вашем диске.

**Геймпад прежде всего.** Каждый экран проходится крестовиной, а текст вводится экранной клавиатурой.

**Тихо и аккуратно.** Звуки интерфейса синтезируются на лету — в проекте нет ни одного звукового файла.
