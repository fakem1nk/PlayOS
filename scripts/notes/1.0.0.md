# PlayOS v1.0.0

> **Major Update: Cloud Data Synchronization & Redesigned UI**

---

## ✨ What's New

- Added cloud synchronization for user profiles, settings, game library, playtime, and game saves.
  - **Supported cloud services:** Yandex Disk, Google Drive, and sync folders (OneDrive, Dropbox, Syncthing).
- Added automatic PC game save detection based on the Ludusavi database and Steam AppIDs. Custom save directories can also be specified manually.
- Added support for keeping multiple save versions when conflicts occur between two PCs. The default is **5 versions**, configurable from **1 to 30**.
- Added the ability to restore data from cloud storage.
- Redesigned the user interface.
- Added theme switching.
- Added customizable UI accent colors, with support for synchronization with DualSense lighting.
- Added platform badges to game covers: **PS2, PS3, and PC**.
- Added the ability to select a display for games running through emulators.
- Added the ability to browse local files directly within the application.
- Added launch options for PS2 and PS3 games.
- Added the ability to disable the overlay globally or for individual games.
- Added a disk space widget to **System Information**.

## 🛠️ Fixed

- Fixed the trophy menu logic when opened from the game information menu.
- Fixed the fade transition delay when navigating from any menu to Settings.

---

Download the appropriate file from the **Assets** section below.

If PlayOS is already installed, you can update directly through the application.
