# PlayOS v1.1.0-beta.3

> **Update: Library, Game Editor & Notification Center**

---

## ✨ What's New

- Added a **Notification Center**: the bell in the top bar keeps the last 50 notifications, so errors, session results and trophies no longer disappear for good.
  - A downloaded update shows up there with a **Restart and update** button.
- Added search and collections to the library: type from the gamepad with live results, group games into your own collections and sort them.
- The home screen now shows your 15 most recent games, and the mouse wheel scrolls the row.
- Hold ✕ (or Enter, or the left mouse button) on a game to open its options; right-click works too. **△** now opens the game page.
- Reworked the game editor: covers, logos and backgrounds are changed by clicking the picture, games can be added straight from Steam, and rarely used fields are tucked under **Advanced**.
- Button hints at the bottom of the screen now follow what is selected.
- Games from the cloud that are not installed on this PC are dimmed, and pressing ✕ asks for the game file.
- When a game fails to launch, PlayOS offers the fix: pick the game file or open the emulator settings.

---

## 🛠 Fixes

- Holding Enter no longer starts a game after the options menu opens.
- Saving a game twice or changing its Steam AppID no longer creates a duplicate in the cloud library.
- Cancelling a launch reliably stops the game, including Steam games that start late.
- The options menu no longer cuts off its last item at a large interface scale.

---

Download the appropriate file from the **Assets** section below.
