# PlayOS v1.2.0-beta.2

> **Update: Smarter Download Sources & Store Content Filter**

---

## ✨ What's New

- Added adding download sources from a file: pick a JSON file or drag it into Settings → Store.
  - Links dragged from the browser are added too.
  - Use it for sites that only let browsers download the file.
- Added the **Adult games** setting in Settings → Store: games with explicit sexual content are hidden from the store unless you turn it on.
- Added downloads for PS2 and PS3 games that are not on this PC, when your sources have them.
- Added clear reasons when a source can't be added: the file was removed, access is denied, or the site only lets browsers in.
- Renamed the sources row to **New releases and fresh updates**.

## 🛠️ Fixed

- Fixed games added from the store staying "not installed" after installing them through Steam.
- Fixed downloads for other platforms (Android, PSP, Xbox, Linux and more) showing up for PC games.
- Fixed downloads of different games with the same name, like a game and its remake, showing up on one page.
- Fixed many downloads not being found: titles with two names, Russian titles and some PC releases are now matched.
- Fixed the store adding a second copy of a game that was already added by hand.
- Fixed short freezes of the gamepad while large sources were loading.
- Fixed sources updating only on startup: they now update when you use the store.
- Fixed backups missing download sources.

---

## 📦 Installation

Download the appropriate file from the **Assets** section below.

If PlayOS is already installed, you can update directly through the application.
