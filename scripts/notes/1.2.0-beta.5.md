# PlayOS v1.2.0-beta.5

> **Update: Redesigned Downloads**

---

## ✨ What's New

- Redesigned the **Downloads** section, in the style of the home screen:
  - All downloads are shown as a row of game covers: the queue on the left, finished downloads on the right.
  - Under each cover there is a progress bar and a short status; a badge on the cover shows pause, errors, passwords, Install and Play.
  - The selected download is shown in detail below: big percent, progress, sizes, folder and buttons with labels.
  - Press a cover to do the main thing right away: pause, resume, install or play.
- Added a live download speed graph, like in Steam.
- Added pixel progress bars in Tivi's style, with a blinking next cell and a running light.
- Added the free space of your download drives to the Downloads header.
- Added **Store** and **Library** buttons to the empty Downloads section.
- Added a close button to the download variants window for the mouse.

## 🛠️ Fixed

- Fixed the Downloads section focusing the close button first instead of your downloads.

---

## 📦 Installation

Download the appropriate file from the **Assets** section below.

If PlayOS is already installed, you can update directly through the application.
