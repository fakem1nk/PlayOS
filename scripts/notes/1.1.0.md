# PlayOS v1.1.0

> **Major Update: VR Games & Smarter Library**

---

## ✨ What's New

- Added VR games: mark any PC game as a VR game, and PlayOS gets everything ready before it starts.
  - **Works with:** Meta Quest over **Link** (cable) and **Air Link** (Wi-Fi).
  - The VR component downloads by itself on the first VR game launch.
- Added VR settings for each game: **Sharpness**, **Show hands**, **Controller vibration** and **Compatibility mode**.
  - If a VR game closes right after launch, PlayOS suggests turning on compatibility mode.
- Added a headset indicator to the top bar: connection type and battery of the headset and both controllers.
- Added a **VR** section in Settings, a **VR** filter in the Library and a headset badge on VR game tiles.
- Added a **Notification Center**: the bell in the top bar keeps the last 50 notifications, so errors, session results and trophies no longer disappear for good.
  - A downloaded update shows up there with a **Restart and update** button.
  - Press **Share** or **View** on the controller to open it.
- Added search and collections to the Library: type from the controller with live results, group games into your own collections and sort them.
  - Press **/** or **Ctrl+F** to search from the keyboard.
- Added a **+** button to the Library for adding games with the mouse.
- Added uninstalling games from the PC right in PlayOS.
  - Steam games are removed through Steam, installed games through their own uninstaller, and everything else goes to the Recycle Bin.
  - The game can stay in your library with its play time, trophies and collections.
- Added automatic game file search: choose the game folder and PlayOS finds the game's EXE in it by itself.
- Added step-by-step guides for the **Steam**, **RetroAchievements** and **SteamGridDB** keys: PlayOS opens the page, picks up the key as soon as you copy it, saves and checks it.
  - Your Steam account and RetroAchievements login are filled in from this PC automatically.
- Added a window frame with **Full screen**, **Minimize**, **Maximize** and **Close** buttons when PlayOS is not in full screen.
- Closing the window now keeps PlayOS running in the tray. Open it again from the tray icon or with the **PS** button; the power button in PlayOS quits completely.
- Added **Vibration in menus** for Xbox controllers and DualSense (off by default).
- Added smooth scrolling with the right stick for long content: game descriptions, trophies, notifications and settings.
- Added support for the mouse **Back** and **Forward** buttons.
- Added the ability to skip the emulator step and set the volume during first setup.
- Redesigned the game editor: covers, logos and backgrounds are changed by clicking the picture, games can be added straight from Steam, and rarely used fields are tucked under **Advanced**.
- Redesigned the update window: a short list of what's new and what's fixed in your language, and one clear button.
  - Small fixes no longer interrupt you: they install when you quit PlayOS.
- Added the ability to go back from a beta to the latest stable version: turn off **Beta testing** in Settings.
- Improved the home screen: it shows your **15** most recent games, and the mouse wheel scrolls the row.
- Improved controls:
  - Hold **Cross** on a game to open its options, or right-click it. **Triangle** opens the game page.
  - Button hints at the bottom of the screen follow what is selected.
  - Holding a direction speeds up smoothly and starts sooner.
  - The mouse and the controller share one focus: pointing at an item selects it.
  - Pressing **Circle** far down the Library first returns to the first row, then to the tabs.
  - An item gives a small nudge when there is nowhere further to go.
  - Clicking the left or right half of a setting value steps it back or forward.
- Improved the on-screen keyboard: hold **Square** to keep erasing, hold **L1/R1** to move the cursor, and typing on a physical keyboard goes straight into the field.
- Games from the cloud that are not installed on this PC are dimmed, and pressing **Cross** asks for the game file.
- When a game fails to launch, PlayOS offers the fix: pick the game file or open the emulator settings.
- Made the cover picker less transparent, so covers are easier to see.
- Error reports are now saved to their own folder instead of the desktop.

## 🛠️ Fixed

- Fixed **F11** not switching PlayOS from full screen to a window.
- Fixed keyboard shortcuts not working with a non-English keyboard layout.
- Fixed the Steam import window lagging and the selected games being hard to add when there are many games.
- Fixed duplicate games in the cloud library after saving a game twice or changing its Steam AppID.
- Fixed cancelling a launch not always stopping the game, especially Steam games that start late.
- Fixed the left stick making two steps at once when tilted diagonally and jittering near the edge of its range.
- Fixed the focus jumping to the first item after closing a dialog or menu.
- Fixed the focus drifting sideways when moving up and down through rows of different width.
- Fixed keys like **C**, **F** or **Backspace** on a physical keyboard closing or editing the on-screen keyboard by accident.
- Fixed **Tab** moving the focus to buttons hidden behind an open window.
- Fixed holding **Esc** or **Backspace** closing several windows in a row.
- Fixed the Profile tab: the right column now scrolls to the end, and the left column no longer overlaps the button hints.
