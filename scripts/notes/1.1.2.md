# PlayOS v1.1.2

> **Update: Meet Tivi & More Reliable Cloud Sync**

---

## ✨ What's New

- Added Tivi, the PlayOS mascot, in the bottom-right corner of the screen.
  - Tivi's LED face follows the focus, blinks and keeps itself busy while you leave the controller alone.
  - Tivi cheers when a game starts, gets sad about errors, falls in love with trophies and dozes off when PlayOS sits idle.
  - Click Tivi for a wink. Keep clicking and see what happens.
- Added a new app icon featuring Tivi, sharp at every size in the taskbar, the Start menu and the tray.
- Cloud sync now tells you when your cloud storage is full or when you need to sign in again, with a **Sign in again** button.

## 🛠️ Fixed

- Fixed cloud sync hanging on a slow or dropped connection.
- Fixed cloud sync taking too long to resume after the connection returns or the PC wakes from sleep.
- Fixed a damaged copy in the cloud being restored over your saves: downloads are now checked first.
- Fixed the version from this PC being lost when you pick the cloud version in a save conflict: it now stays in the save history.
- Fixed changes getting lost when two PCs have their clocks set differently.
- Fixed conflict copies made by OneDrive, Dropbox or Syncthing showing up as extra devices and keeping old saves in the cloud.
- Fixed cloud sync showing **Syncing…** forever when save sync is turned off.
- Fixed a broken profile or library file in the cloud stopping game saves from syncing.
