# PlayOS v1.1.0-beta.2

> **Major Update: VR Games & Easier Beta Testing**

---

## ✨ What's New

- Added VR games: mark any PC game as a VR game, and PlayOS gets everything ready before it starts.
  - **Works with:** Meta Quest over **Link** (cable) and **Air Link** (Wi-Fi).
  - The VR component downloads by itself on the first VR game launch.
- Added VR settings for each game: **Sharpness**, **Show hands**, **Controller vibration** and **Compatibility mode**.
- Added a headset indicator to the top bar: connection type and battery of the headset and both controllers.
- Added a **VR** section in Settings, a **VR** filter to the Library and a headset badge on VR game tiles.
- Added the ability to go back from a beta to the latest stable version: turn off **Beta testing** in Settings. Your games, settings and progress stay.
- Redesigned the update window: a short list of what's new and what's fixed in your language, a **Beta** badge, and one clear button.
  - Small fixes no longer interrupt you: they install when you quit PlayOS.

## 🛠️ Fixed

- Fixed adding Source 2 games: PlayOS picks the real game file by itself and turns on VR for **Half-Life: Alyx**.

---

## 📦 Installation

Download the appropriate file from the **Assets** section below.

If PlayOS is already installed, you can update directly through the application.
