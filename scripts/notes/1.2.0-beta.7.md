# PlayOS v1.2.0-beta.7

> **Major Update: Game Catalogue & Download Control**

---

## ✨ What's New

- Added a **Game Catalogue** to the Store with the whole Steam catalogue in one grid:
  - Sort by popularity, new and trending, top rated or name.
  - Filter by genre and subgenre, release year or decade, Russian interface or voice-over, review score, camera, game mode, style, story, world and mood.
  - Hide Early Access games or show only games you can download.
  - Genre rows on the Store home open the catalogue.
- Added games beyond Steam to the Store:
  - GOG games that are not on Steam appear in search, on their own pages and in an **Only on GOG** row.
  - Games known only to your download sources get their own store pages with artwork and a description.
- Added quick adding to the library: a game can be added straight from its cover without opening its page.
- Added download management:
  - Downloads, unpacking and seeding pause while a game is running and continue when it closes.
  - Added download and upload speed limits.
  - Added **Download now** and moving downloads up or down in the queue.
  - Added choosing which files of a torrent to download.
  - Added optional seeding after a download, up to a chosen ratio.
- Redesigned the Store banner: arrows outside its edges, an Add to library button and page dots in the corners.

## 🛠️ Fixed

- Fixed long descriptions and tags pushing the game logo out of the Store banner.
- Fixed store covers not showing the in-library check for games added without a Steam AppID.

---

Download the appropriate file from the **Assets** section below.
