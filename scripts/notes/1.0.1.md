# PlayOS v1.0.1

> **Update: Performance & Steam Emulator Achievements**

---

## ✨ What's New

- Added achievement support for games running through Steam emulators.
  - **Supported emulators:** RUNE, CODEX, Goldberg / GSE, EMPRESS, OnlineFix, and RLD!
  - Achievement names, icons, and rarity are loaded from Steam.
- Added clearer messages when a game has no Steam achievements to show.
- Added a **Game folder** field to the game editor. It is used for game size, local files, save detection, and playtime tracking.
- Replaced the game process field with **Launch EXE**.
- Added the detected save folder and Steam AppID to the game editor.
- Added the **Synced via Steam** cloud status for Steam games.
- Added cloud status for games that have not been synced yet and for games that are currently running.
- Added a cloud step and a language selector to the first-run setup. English is now the default language.
- Added the ability to move the window when it is not in full screen.
- Added the **Free up memory** option: while a game is running, PlayOS unloads its interface and keeps only the overlay.
- Added performance optimizations.
  - PlayOS runs in Windows efficiency mode while a game is running.
  - The hidden overlay no longer uses the GPU.
  - Game art is loaded in reduced size, which lowers memory usage.
  - Large libraries load faster and scroll more smoothly.
  - PlayOS starts faster.

## 🛠️ Fixed

- Fixed the gamepad controlling PlayOS on a second monitor while a game is running.
- Fixed hint buttons overlapping the interface in Settings, the game editor, the game page, and the trophy list, including at **125%** scaling.
- Fixed the overlay flickering and closing in full-screen games.
- Fixed full-screen games staying minimized after the overlay was closed.
- Fixed short stutters in some games when DualSense or DualShock 4 controllers were detected.

Download the appropriate file from the **Assets** section below.
