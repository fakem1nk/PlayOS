# PlayOS v1.2.0-beta.1

> **Major Update: Game Store & Download Sources**

---

## ✨ What's New

- Added the **Store** tab with a featured banner and rows of top sellers, new and trending, most played and upcoming games.
  - Search covers the whole Steam catalogue, including games that are not sold in your region.
  - The store opens instantly from cache and keeps working offline.
- Added store game pages with a video preview, the full description, screenshots with a full-screen viewer, details and HowLongToBeat times.
- Added **download sources**: add a link to a JSON file with a list of downloads (Hydra format) in Settings → Store.
  - PlayOS ships no sources and only reads the ones you add.
  - Games from your sources get a download mark in the store and appear in the **New releases** row.
- Added games from the store to your library: a game that is not installed on this PC shows **Download**.
  - **Download** lists the options from your sources: copy a link or open it in your torrent client or browser.
  - **Wrong game?** hides an option that was matched to the wrong game.
  - Without any sources, PlayOS tells you to add one and opens the right settings.
- Holding ✕ on a game now opens its page, and △ opens the game options.

---

## 📦 Installation

Download the appropriate file from the **Assets** section below.

If PlayOS is already installed, you can update directly through the application.
