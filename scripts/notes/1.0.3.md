# PlayOS v1.0.3

> **Patch: Save Detection Fixes**

---

## 🛠️ Fixed

- Fixed the game editor showing "not found" for the save folder when saves were found on different drives.
- Fixed the game editor showing a too general folder, such as the user profile, as the save folder.
- Fixed the Steam AppID and Steam emulator files not being detected when they are next to the game EXE instead of the game folder.
- Fixed save detection and playtime tracking when the game folder was moved, deleted, or set to a folder with many other games.
- Fixed a failed save check being shown as "not found" in the game editor.

---

Download the appropriate file from the **Assets** section below.
