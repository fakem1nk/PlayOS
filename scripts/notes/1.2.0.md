# PlayOS v1.2.0

> **Major Update: Game Store & Downloads**

---

## ✨ What's New

- Added the **Store** tab with a featured banner and rows of top sellers, new and trending, most played and upcoming games.
  - Search covers the whole Steam catalogue, including games that are not sold in your region.
  - The store opens instantly from cache and keeps working offline and on unstable connections.
  - Rows and the banner can be scrolled by dragging with the mouse.
- Added a **Game Catalogue** with the whole Steam catalogue in one grid:
  - Sort by popularity, new and trending, top rated or name.
  - Filter by genre and subgenre, release year or decade, Russian interface or voice-over, review score, camera, game mode, style, story, world and mood.
  - Hide Early Access games or show only games you can download.
- Added GOG games that are not on Steam: they appear in search, on their own pages and in an **Only on GOG** row.
- Added store game pages with a video preview, the full description, screenshots with a full-screen viewer, details and HowLongToBeat times.
- Added adding games from the store to your library: from the game page, from the banner or straight from a cover.
- Added **download sources**: add a JSON file with a list of downloads (Hydra format) by link, from a file or by dragging it into Settings → Store.
  - PlayOS ships no sources and only reads the ones you add.
  - Games from your sources get a download mark and appear in the **New releases and fresh updates** row.
  - Games known only to your sources get their own store pages, and PS2 and PS3 downloads are found for emulator games.
- Added the **Adult games** setting: games with explicit sexual content are hidden from the store unless you turn it on.
- Added downloads right inside PlayOS: press **Download** on a game and pick a variant from your sources.
  - Direct links resume after a pause or a restart and try the next mirror when one fails.
  - Torrent and magnet links download through PlayOS's own client, and you can choose which files to download.
- Added the **Downloads** section, opened with the top bar button that shows the progress as a ring:
  - All downloads are shown as a row of game covers with a pixel progress bar and a short status under each.
  - The selected download is shown in detail: big percent, a live speed graph, sizes, folder and buttons with labels.
  - **Download now**, move downloads up or down in the queue, pause, resume or cancel them.
- Added choosing where each game is downloaded: pick a folder by free space or create a new one in one press.
- Added automatic unpacking of zip, 7z, rar and multi-part archives; the password is asked only when it is needed.
- Added installing games after the download:
  - Ready-to-play games, PS2 images and PS3 games go to your library on their own.
  - Games with an installer get an **Install** button, which then turns into **Play**.
- Added pausing downloads while a game is running; they continue when it closes.
- Added download and upload speed limits and optional seeding after a download, up to a chosen ratio.
- Added clickable download notifications that open **Downloads**.
- Added a **Stack** and a **Shelf** to the profile:
  - Stack up the games you want to finish: the top one becomes the current game, the rest wait with the time left from HowLongToBeat.
  - Mark a game as **Cleared** to put it on the shelf, with a mood rating and an optional 100% mark.
  - The shelf keeps all cleared games in one row, grouped by year, with a recap of each year.
  - Collect seven **Tivi figures** as you clear games.
- Added a year activity calendar to the profile with your current and best streaks.
- Redesigned Tivi: glowing ear capsules instead of antennas react to every emotion, the body is flat, and the screen got two extra rows of dots.
  - Tivi now reacts to notifications and to a low controller battery.
- Added an option to start PlayOS minimized to the tray with Windows.
- Holding ✕ on a game now opens its page, and △ opens the game options.
- Button hints now switch to keyboard keys while you use the mouse.
- The **Recently played** row now shows only games you have played, with the running game first.
- Installed games are now shown first in the Library.
- Games whose files were deleted are now marked as not installed automatically.

## 🛠️ Fixed

- Fixed games that need administrator rights not starting.
- Fixed uninstalling games installed in folders with square brackets in the name.
- Fixed a PC shutdown or restart being reported as a PlayOS crash.
- Fixed older play sessions disappearing from the history: up to **600** sessions per game are now kept.
- Fixed uploads to the cloud failing with an out-of-range delay error.

## 🗑️ Removed

- Removed the Most Played and Game Trophies sections from the profile; game trophies are still on the game page.
