# PlayOS v1.0.4

> **Patch: Cleaner Settings & Navigation Fixes**

---

## ✨ What's New

- Redesigned Settings: sections are grouped into **Games**, **Interface** and **System**, with fewer and clearer pages.
- Added a separate volume for background music: **Off / Quiet / Medium / Loud**.
- Added automatic trophy account checks: RetroAchievements and Steam show their connection status right under their fields.
- Added the ability to cancel a game launch with the **Back** button.
- Added the ability to change your name right on the **Profile** tab.
- Improved text fields: they open for typing only after pressing **Cross**, **Enter** or clicking, and **Enter** saves the value.
- Improved the cloud page: **Sign out** is now next to **Sync**.
- Renamed **Free up memory** to **Low-end PC mode**.
- Combined interface sounds and their volume into one setting, and live backgrounds and animated covers into another.

## 🛠️ Fixed

- Fixed saving changes to a game after trophy screenshots were taken for it.
- Fixed the menu responding to the controller while a game was launching.
- Fixed the focus jumping to a button below when there was nothing in the pressed direction.
- Fixed the focus getting stuck on some text fields in Settings.
- Fixed the arrows next to setting values not working with the mouse.

## 🗑️ Removed

- Removed the full screen toggle. Press **F11** to switch between a window and full screen.
- Removed the light bar test button.
- Removed the break reminder.

---

Download the appropriate file from the **Assets** section below.
