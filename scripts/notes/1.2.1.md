# PlayOS v1.2.1

> **Patch: Cloud Sync Security**

---

## 🛠️ Fixed

- Fixed cloud saves being able to write files outside the game's save folders.
  - Saves from the cloud now go only into the save folders of their game. A copy with anything else is rejected, and the saves on this PC stay as they are.
  - Programs, scripts and shortcuts are no longer uploaded with saves or accepted from the cloud.
- Fixed cloud saves being able to change any setting in the Windows registry. Only the game's own registry keys are restored now.
- Fixed a damaged or altered profile in the cloud being able to break the profile picture, settings or library on another PC.
- Fixed very large or broken files in the cloud being able to slow down or freeze PlayOS.
- Fixed cloud sync sometimes stopping until restart when the sign-in server didn't respond.
- Launch options are no longer synced between PCs: each PC keeps its own.

---
