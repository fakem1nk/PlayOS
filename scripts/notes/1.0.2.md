# PlayOS v1.0.2

> **Update: Instant Trophies & Interface Polish**

---

## ✨ What's New

- Added instant trophy notifications for Steam games and games running through Steam emulators.
  - Trophies now appear right after unlocking instead of once a minute.
  - Games with Steam emulator achievements no longer need a Steam API key for notifications.
- Added a screenshot of the unlock moment, shown next to the trophy in the trophy list.
- Added recent trophies to the profile.
- Added a confirmation before resetting the controller layout and before signing out of the cloud.
- Added a warning when leaving the game editor with unsaved changes.
- Added support for the Windows **Reduce motion** setting: animations become simpler and decorative effects stop.
- Improved readability on TVs: secondary text is larger and has higher contrast.
- Improved the quick saves list in the overlay: empty slots are collapsed until you need them.
- Improved the light theme on the home screen: game art is no longer washed out.

## 🛠️ Fixed

- Fixed glass panels and buttons not blurring the game art behind them.
- Fixed the activity bars in the profile having different lengths for different games.
- Fixed setting values wrapping onto two lines.
- Fixed text on games without cover art being hard to read in the light theme.
- Fixed the session timer being hard to read in the overlay in the light theme.
- Fixed the data folder path breaking in the middle of a word in system information.
- Updated Electron with the latest security fixes.

---

Download the appropriate file from the **Assets** section below.
