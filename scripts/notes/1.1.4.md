# PlayOS v1.1.4

> **Update: Updates With Tivi**

---

## ✨ What's New

- Added an install screen for updates, so PlayOS no longer looks like it just shut down.
  - Tivi catches pieces of the update with his antenna, puts them together and reboots while the installer works.
  - The screen stays up until the new version opens.
- Added a finish to the update: after installing, Tivi celebrates, the screen confirms the new version, and PlayOS starts as usual.
  - A short chime plays if sounds are on.
- Redesigned Tivi's loading spinner.

---

## 📦 Installation

Download the appropriate file from the **Assets** section below.

If PlayOS is already installed, you can update directly through the application.
