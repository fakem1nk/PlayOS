# PlayOS v1.2.0-beta.4

> **Update: Cleaner Download Variants & Install Fix**

---

## ✨ What's New

- Redesigned the download variants window: the game cover on top, cleaner rows with who made the release, version and labels, and a download arrow on the selected variant.
  - **Open in another program** and **Close** at the bottom can be clicked with the mouse.
- Added clickable notifications: press a download notification to open **Downloads**.
- Added an animation while the store searches, so it is clear the search is still running.

## 🛠️ Fixed

- Fixed **Install** not starting installers in folders with square brackets in the name.
- Fixed uninstalling games installed in folders with square brackets in the name.
- Fixed broken characters in some download names.

## 🗑️ Removed

- Removed the **Wrong game?** and **Copy link** buttons from the download variants.

---

## 📦 Installation

Download the appropriate file from the **Assets** section below.

If PlayOS is already installed, you can update directly through the application.
