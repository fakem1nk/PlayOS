# PlayOS v1.2.2

> **Update: New Tivi, New Intro & Safer Cloud Saves**

---

## ✨ What's New

- Redesigned Tivi: short round ears and little feet.
  - His ears now move: they perk up, droop, flap and twitch with his mood.
  - He stomps, taps a foot and tucks his feet in when he jumps.
  - When left alone, Tivi twitches an ear, pricks up both ears or shuffles on the spot.
  - The collectible Tivi figures in the profile got the same look.
- Redesigned the app icon to match the new Tivi.
- Redesigned the intro and the farewell screen.
  - The PlayOS name now rains down into place and collapses towards its center on exit.
  - The ring at power-on is replaced by a wave that scrambles the symbols as it passes.
  - At the end of the intro the symbols fly into the corner and Tivi appears there.
  - On exit Tivi yawns and goes dark first, then the screen follows.
- Added a second scene to the update install screen, so the animation no longer repeats back to back.
- Added a history of cloud saves: besides the latest versions, PlayOS keeps one save per day for a week and one per week for **5 weeks**, up to **256 MB** per game.
- Added waiting for cloud saves when a game starts, with an option to play without waiting.
- Added a confirmation before cloud sync removes many games from the library at once.
- PlayOS now finishes cloud sync before quitting, shutting down the PC or installing an update.

## 🛠️ Fixed

- Fixed a damaged library file leaving PlayOS with an empty library: the last good copy is loaded, and the damaged file is kept.
- Fixed cloud saves being left half-restored if something went wrong in the middle.
- Fixed edits of the same game on two PCs overwriting each other: changes are now merged field by field.
- Fixed torrents that downloaded very quickly being seeded forever instead of stopping at the set ratio.
- API keys are now stored encrypted and stay on each PC.
- All of Tivi's animations now run on one rhythm.

---

Download the appropriate file from the **Assets** section below.
